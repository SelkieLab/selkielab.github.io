项目

目前 1 个，慢慢加

bot-panel

活跃 Python MIT

AstrBot + SnowLuma 的控制面板。把 QQ 机器人的日常运维收进一个网页： 容器状态、实时日志、插件市场、人格提示词、扫码登录、知识库，全在一个界面里。

后端单文件 server.py，纯 Python 标准库，零第三方依赖
前端MD3 单页应用，partials 分片加载，移动端可用，PWA 离线兜底
运维2700+ 插件分页 / 分类 / 排序、安装卸载更新、SSE 实时日志
安全PBKDF2 口令、TOTP 两步验证、会话失效、审计日志、QQ / webhook 告警
部署systemd 非特权用户 + 只读文件系统 + 最小 syscall 集合
备份每日自动，sqlite 在线快照，只备不可再生数据
bash 
# 需要 Python 3.8+ 和 Docker
git clone https://github.com/SelkieLab/bot-panel.git
cd bot-panel
PANEL_INIT_PASSWORD='你的密码' python3 server.py
