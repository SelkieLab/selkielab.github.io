bot-panel

在跑 Python MIT

QQ 机器人（AstrBot + SnowLuma）的运维面板。原来是 SSH 进去敲 docker 命令、 改 JSON 重启容器，现在这些事在一个网页里点。插件市场、实时日志、人格提示词、 扫码登录、知识库都在里面。

后端
一个 server.py，只用标准库，没有任何 pip install
前端
MD3 单页应用，分片加载，手机上能用，离线时有兜底页
插件
市场里 2700 多个，分页浏览，能装能卸能更新
日志
docker logs 实时推流，断线自动重连
安全
口令走 PBKDF2，可开两步验证，改密后旧会话立刻失效，关键操作留审计
部署
非特权用户跑，文件系统只读，syscall 白名单
bash 
# 需要 Python 3.8+ 和 Docker
git clone https://github.com/SelkieLab/bot-panel.git
cd bot-panel
PANEL_INIT_PASSWORD='你的密码' python3 server.py

做法

几条会反复用到的判断

能少一个依赖就少一个

标准库写得出来就不引入包。不是为了省体积，是不想三年后因为某个包弃更而跑不起来。

周末能读完

一个人读不完的架构等于没人维护。宁可砍功能，也不写需要画图才讲清楚的代码。

安全上不将就

面板这种东西被拿到就等于整台机器。这里没有"先这样，以后再补"。

先解决自己的问题

按实际需求写，不提前抽象。等第二次重写时，该抽什么自然就清楚了。

技术

清单比形容词有用
Python 3.8+ 原生 JavaScript Docker systemd SQLite Let's Encrypt

没有构建步骤 0 个工具链

不打包、不转译、不装 node_modules。浏览器打开 index.html 看到的就是最终产物，改一行保存刷新即见。

没有前端框架 ~130 KB

DOM 操作是 querySelector 那套原生的，组件照 MD3 规范手写。整站 CSS 加 JS 大约 130 KB，不含字体。

没有第三方依赖 stdlib

http.server 起服务，sqlite3 读库，hashlib 算口令，hmac 做 TOTP。全都是 Python 自带的。

镜像锁 digest @sha256

compose 里写的是具体 digest 而不是 :latest。升级要自己改一行再 up -d，不会哪天睡醒发现版本变了。

上手

拿 bot-panel 举例
1
装好 Python 和 DockerPython 3.8 以上就行，Docker 用来跑 AstrBot 和 SnowLuma 两个容器。
2
克隆，设个初始口令，启动其余配置都在网页里填，包括上游账号、是否开两步验证、告警发到哪。
3
把 HTTPS 配上面板可以直接读证书，也可以放在 Nginx 或 Caddy 后面。裸 HTTP 挂公网等于明文发密码。
4
收窄端口，开两步验证安全组只放行自己的 IP。顺手把 TOTP 打开，密码泄露也进不来。
